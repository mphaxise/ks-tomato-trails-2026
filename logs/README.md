# Field Logs

Use this folder for freeform notes that don't fit neatly into the weekly CSV data.

Good things to log here:
- Unusual weather events (surprise heat wave, heavy rain, dense fog streak)
- Pest sightings (aphids, hornworms, whitefly)
- Interventions (foliar spray, fertilizer type, support changes)
- General garden observations and intuitions

## Naming Convention

`YYYY-MM-DD_notes.md` — one file per entry, dated.

Example: `2026-07-12_hornworm_found_on_brandywine.md`
