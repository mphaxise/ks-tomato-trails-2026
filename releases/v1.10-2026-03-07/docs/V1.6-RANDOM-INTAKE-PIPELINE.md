## Standard Intake Routine For New Batches

Use this sequence for each new Google Photos pull:

1. Batch partitioning:
   - Group by `capture_date` and `uploaded_at`.
   - Validate row count and duplicate `source_asset_id`.
2. Frame-type routing:
   - Route each row into `baseline_single_pot`, `watering_day_sequence`, or `random_context`.
   - Gate with blur/brightness quality checks.
3. Pot detection:
   - Detect pot regions before reading text.
   - Keep multi-pot candidates for random/context images.
4. Label extraction (weak signal):
   - OCR label regions only; parse `pot_tag`, `packet_tag`, numeric tokens.
   - Keep OCR confidence and raw excerpt as provenance.
5. Identity resolution (strong signal):
   - Apply manual pot overrides first.
   - Apply baseline continuity by `pot_id`.
   - Use historical/series fallback.
   - Use sequence inference only for near-complete watering-day runs.
6. Confidence and review queue:
   - Auto-publish only `ready_*` rows.
   - Route unresolved rows to `capture`, `ocr`, or `mapping` review stages.
7. Persist and learn:
   - Store `resolution_source`, mapping notes, and drift metrics.
   - Feed corrected rows back into overrides/training data.
