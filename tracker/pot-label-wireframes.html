Pot Labeling UI Prototypes

UI-only wireframes to compare interaction models before implementation.

What You Will See In Each Prototype

Each page shows a different way to label pots, add notes, and mark images as not usable for training.

Inspiration note: Option G is inspired by MathWorks Image Labeler app patterns (toolstrip, label-definition panes, canvas, and image browser). Source: MathWorks documentation.

Option A: Canvas Inspector

Large image canvas with editable boxes, plus a detailed side form for one selected pot.

Option B: Guided Stepper

Step-by-step workflow with a filmstrip so you move through one image at a time in order.

Option C: Batch Grid

Many thumbnails at once for quick scanning, with a sticky editor for fast review actions.

Option D: Run Timeline

Timeline of garden run dates, then focused editing for a chosen day and photo.

Option E: Pot Board

Kanban-style status lanes (confirmed, needs review, no basis) organized by pot state.

Option F: Cross-Day Compare

Two-image side-by-side comparison to verify if a pot match is consistent across days.

Option G: MathWorks-Inspired Labeler

Desktop labeler style with tabbed toolstrip, left label definitions, bottom browser, and right review pane.
