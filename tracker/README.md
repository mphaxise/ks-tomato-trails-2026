# Tracker App (Future)

This folder is reserved for a future web-based or mobile logging interface that replaces manual CSV entry.

## Possible Features
- Weekly observation form (auto-generates CSV row)
- Photo upload per plant per week
- Live season dashboard (Fog Belt Score progress bar per variety)
- Fog weather correlation chart
- End-of-season report generator

## Tech Stack Options
- Simple: Google Forms → Google Sheets (zero-code)
- Medium: Next.js + local CSV read/write
- Full: React + Node.js + SQLite, deployable to Cloudflare Pages

See `BRAINSTORM.md` in root (if created) for feature extensions.
