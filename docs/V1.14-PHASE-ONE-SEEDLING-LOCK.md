## Purpose

- **Day 1 of Phase 1**: `2026-02-27`

   - `phase_end_run_date=2026-03-11`
   - `phase_end_label=Last Day of Phase 1`
2. Anchor run override counts must remain:
   - `2026-02-27` -> 32 reviewed rows / 32 unique pots
   - `2026-03-11` -> 33 reviewed rows / 32 unique pots (includes backfilled `21T`)
3. End-run reconciliation directives must persist:
   - row `432` excluded as duplicate
   - row `435` retained as canonical `25T`

4. Cross-run pot/varietal consistency and duplicate-pot checks must pass.
