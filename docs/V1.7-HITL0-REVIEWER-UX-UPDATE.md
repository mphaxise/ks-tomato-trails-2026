## Changes Shipped

1. Signal classification added per row:
- `TYPE_I` -> `OCR match`
- `TYPE_II` -> `Weak OCR`
- `TYPE_III` -> `No signal - sequential guess`

2. Type III suggestion framing changed:
- from `Suggested Pot: XT`
- to `Unverified placeholder: XT (based on sequence position only)`

3. New reviewer verdict option:
- `No basis - cannot verify from this photo`

4. Filtering and queue triage controls:
- Added `Signal Tier` filter in toolbar.
- Rows are sorted by signal rank (strongest first).

5. OCR transparency in label view:
- Label crop shows OCR-number overlays with bounding boxes when detected.
- Overlays are generated from Tesseract TSV token boxes.

## Verification Checks

Confirmed in generated page:
- Signal-tier badge visible on cards.
- `Signal Tier` filter present.
- New no-basis verdict option present.
- Type III cards render unverified-placeholder wording.

## Known Limits

- Most rows currently have zero match variants; overlay boxes may be empty or sparse.
- Overlay boxes reflect OCR token locations, not a guaranteed pot-label detector.
