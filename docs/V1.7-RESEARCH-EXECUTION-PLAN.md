## Sprint 0 plan (start now)

### SW-0: OCR crop targeting diagnosis

Goal: classify root cause of `OCR Match Variants: 0` as crop-targeting issue, label absence, or OCR engine issue.

Inputs:
- `data/research/v1_6/ocr_recovery/manual_label_queue.csv`
- `data/research/v1_6/ocr_recovery/manual_label_queue/`
- `tracker/hard-row-reviewer.html`

Execution tasks:
1. Sample 10 queue rows across both weak runs.
2. Build an audit table with columns:
- `row_id`
- `run_date`
- `label_crop_has_label` (yes/no)
- `full_crop_has_label` (yes/no)
- `ocr_numbers_detected`
- `detected_numbers_source_guess`
- `root_cause_class`
3. Save findings to:
- `data/research/v1_7/sw0_ocr_crop_diagnosis.csv`
- `docs/V1.7-SW0-OCR-CROP-DIAGNOSIS.md`

Pass criteria:
- Root-cause class assigned for all sampled rows.
- Dominant failure mode identified with supporting examples.

### SW-0b: reviewer signal quality audit

Goal: quantify signal quality distribution over all currently queued rows.

Execution tasks:
1. Classify each row as `TYPE_I`, `TYPE_II`, or `TYPE_III`.
2. Produce summary counts and percentages.
3. Save outputs to:
- `data/research/v1_7/sw0b_signal_quality_audit.csv`
- `data/research/v1_7/sw0b_signal_quality_summary.json`
- `docs/V1.7-SW0B-REVIEWER-SIGNAL-AUDIT.md`

Pass criteria:
- Full queue classified.
- Share of zero-evidence placeholders is explicit.

### HITL-0: minimum viable reviewer UX fix

Goal: make reviewer UI honest about evidence quality before more review work.

Required UI changes (existing page: `tracker/hard-row-reviewer.html`):
1. Add per-row signal badge:
- `OCR match`
- `Weak OCR`
- `No signal - sequential guess`
2. Add verdict option: `No basis - cannot verify from this photo`.
3. Group or sort rows by signal quality.
4. On no-signal rows, replace "Suggested Pot" framing with "Unverified placeholder".
5. Display OCR numbers and bounding-box metadata when available.

Output artifacts:
- updated reviewer page + assets
- `docs/V1.7-HITL0-REVIEWER-UX-UPDATE.md`

Pass criteria:
- At least one screenshot/example per signal tier documented.
- Reviewer can explicitly mark no-basis rows.
