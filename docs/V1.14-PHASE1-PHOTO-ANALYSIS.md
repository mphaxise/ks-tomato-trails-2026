## Method

1. Export canonical pot pairings from the reconciled mapping logic for `2026-02-27` and `2026-03-11`.
2. Download every paired photo locally and inspect all pots side by side.
3. Assign each pot to one of four buckets:
   - `strong_establishment`
   - `modest_establishment`
   - `stalled_or_failed`
   - `missing_last_day`

Important limitation:

- These two runs are good for qualitative establishment review, but not for precise pixel-area growth measurement.
- Framing and camera distance differ enough between the runs that exact canopy-size comparisons would need scale normalization first.

## Cross-Pot Patterns

### 1. Most pots did establish by the end of Phase 1

The strongest visual signal in the pair set is not decline; it is broad early establishment. Many pots moved from cotyledon-scale sprouts to clearly readable seedling structure by `2026-03-11`.

Examples:

- `1T`, `2T`, `4T`, `5T`, `8T`, `11T`, `14T`, `18T`, `19T`, `20T`, `22T`, `25T`, `29T`, `30T`, `31T`, `32T`

These are good candidates for:

- reference examples in tracker pages
- first-pass visual training seeds
- “healthy baseline” comparisons for weaker pots

### 2. Weak pots are mostly weak because they stayed small, not because they clearly collapsed

Most watchlist pots still show some growth. The issue is limited establishment rather than obvious disappearance.

That matters for project logic:

- These should be treated as `needs follow-up`, not automatically as dead or mislabeled.
- A simple binary `alive/dead` label would lose important signal; a `strong/modest/stalled/missing` bucket is more useful.

### 3. A few pots show environmental risk signals beyond simple vigor

Several end-of-phase images show very wet media and visible white/fuzzy surface growth.

Most notable:

- `18T`
- `20T`
- `23T`

This does not prove disease from photos alone, but it is enough to flag:

- watering intensity
- airflow/humidity
- damping-off or mold monitoring

### 4. Some pots likely need thinning decisions

Multiple “strong” pots show more than one viable stem/seedling in the same pot by the last-day image.

This is useful project-side because it affects both:

- gardening decisions: whether the experiment wants one dominant plant per pot
- image analysis decisions: multi-stem pots complicate canopy scoring and later phenotype tracking

## What The Photos Support Reliably

These analyses are already credible from the current pair set:

- pot-level establishment triage
- watchlist generation
- pair-completeness audit and backfill validation
- rough variety-level early vigor summary
- detection of obvious multi-seedling competition
- detection of visible wet-media / mold-risk cues
- selection of strong reference pots for future computer-vision work

## What Is Not Yet Reliable Without Better Standardization

These analyses should wait for a more standardized capture setup:

- exact growth-rate scoring from raw canopy area
- direct biomass proxies from pixel count
- strong claims about relative plant size across runs
- fine-grained leaf-count or branching-count automation

To make those reliable, future runs should keep:

- fixed camera distance
- fixed pot placement
- consistent lighting
- a scale reference in frame

## Project Use

This review is already useful for the tomato trails project in four concrete ways:

1. It narrows the human follow-up queue to `10` pots instead of all `32`.
2. It identifies a strong reference cohort for tracker examples and future CV seed tasks.
3. It surfaces environmental cues (wet media / possible mold pressure) that are not captured by pot identity alone.
4. It argues for a standardized recapture protocol if the project wants quantitative image-based growth scoring next.
